## 🔄 Development Workflow

This repository is integrated with [v0.app](https://v0.app) for AI-assisted development.

The development workflow:

1. Create and modify the portfolio using v0.
2. Preview changes through the v0 interface.
3. Sync changes with the connected GitHub repository.
4. Vercel builds and deploys updates from the configured production branch.
5. Verify the latest changes on the live website.
